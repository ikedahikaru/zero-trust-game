# ZERO / TRUST

匿名のハッカーになって、相手の4桁パスワードを破る正体隠匿ゲームです（4〜10人）。
チャットでは嘘をついてもかまいませんが、システムが返す解析結果は必ず正しいです。

## 遊び方

### ひとりで遊ぶ（CPU戦）
タイトル画面で人数を選び、「ひとりで開始」を押します。

### オンライン対戦
1. ホストは「部屋を作る」を押します。
2. 表示されたルームコードかURLを、一緒に遊ぶ人に送ります。
3. 参加者はタイトル画面でルームコードを入力して「参加」を押します（URLを開いた場合は、コードが入力済みになります）。
4. ホストが参加人数を選んで「オンライン対戦開始」を押します。人間の人数が足りない分は、CPUが入ります。

- 4〜10人で遊べます。iPhone・Android・PCのブラウザで動きます。
- 通信はブラウザ同士の直接接続（WebRTC / [PeerJS](https://peerjs.com/)）です。ゲームの処理はホストのブラウザで行い、各プレイヤーには本人が見てよい情報だけを送ります。
- 試合中に接続が切れたプレイヤーは、CPUが代わりに行動します。同じ端末・同じブラウザで同じ部屋に入り直すと、元の席に戻れます。
- ホストがページを閉じると、試合は終了します。

### 制限
- ホストのブラウザはゲーム全体の情報を持っています（開発者ツールを使えば見えます）。信頼できる人がホストをしてください。
- 一部のモバイル回線や社内ネットワークでは、直接接続できないことがあります。その場合はWi-Fiなど別の回線で試してください。

## ルール

## BGM
- タイトル画面：`bgm/title.mp3`、試合中：`bgm/action.mp3`（Suno で作成）
- ブラウザの仕様で、最初に画面をタップ・クリックしたときに再生が始まります。右下のボタンで ON / OFF を切り替えられます（設定はブラウザに保存されます）。

## ファイル構成
- `index.html`：ゲーム本体（HTML・CSS・JavaScriptの1ファイル）
- `bgm/`：BGM（mp3）
- `SPEC.md`：仕様と実装メモ
